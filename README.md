## English 

### 📄 About The Project
 A modern, responsive, and high-performance landing page developed for a fictional medical clinic. Built with an emphasis on industry best practices, clean component architecture, optimized local SEO, and patient conversion via direct WhatsApp integration. 
 
 🔗 **Live Demo:** [https://clinicavidaesaude.vercel.app/](https://clinicavidaesaude.vercel.app/) 
 
 ### 🛠️ Tech Stack 
 
 * **[Next.js 14 (App Router)](https://nextjs.org/):** React framework for routing and performance optimization. 
 * **[React](https://reactjs.org/):** UI library for modular component-based architecture. 
 * **[TypeScript](https://www.typescriptlang.org/):** Static typing for code reliability and scalability. 
 * **[Tailwind CSS](https://tailwindcss.com/):** Utility-first CSS framework for mobile-first responsive design. 
 * **[Vercel](https://vercel.com/):** Cloud platform for continuous deployment (CI/CD). 
 
 ### ✨ Key Features & Best Practices 
 * **Clean Component Architecture:** Isolation of reusable UI parts (e.g., `ServicoCard`). 
 * **SEO & Open Graph Protocol:** Dynamic metadata setup for rich social media card previews (WhatsApp, LinkedIn, Telegram). 
 * **Media Optimization:** Native `next/image` usage for lazy loading and optimized image rendering. 
 * **Semantic HTML:** Proper structural elements (``, ``, ``) for accessibility. 
 
 ### 🔧 Getting Started Locally 
 
 ```bash 
 
 # Clone the repository 
 
 git clone https://github.com/eliasmaia/landing-page-clinica.git 
 
 # Go to the project directory 
 
 cd landing-page-clinica 
 
 # Install dependencies 
 
 npm install 
 
 # Run the development server 
 npm run dev
 ```
 
 Open [http://localhost:3000](http://localhost:3000) with your browser to see the live application. 
 

 ## Português 
 
 ### 📄 Sobre o Projeto
 
  Uma landing page moderna, responsiva e de alta performance desenvolvida para uma clínica médica fictícia. O projeto foi construído focando em boas práticas de mercado, arquitetura de componentes limpa, SEO local otimizado e conversão de pacientes via integração direta com o WhatsApp. 
  
  🔗 **Link da Aplicação no Ar:** [https://clinicavidaesaude.vercel.app/](https://clinicavidaesaude.vercel.app/) 
  
  ### 🛠️ Tecnologias Utilizadas 
  * **[Next.js 14 (App Router)](https://nextjs.org/):** Framework React para renderização e otimização de rotas. 
  * **[React](https://reactjs.org/):** Biblioteca para construção da interface baseada em componentes reutilizáveis. 
  * **[TypeScript](https://www.typescriptlang.org/):** Tipagem estática para maior segurança e manutenibilidade do código. 
  * **[Tailwind CSS](https://tailwindcss.com/):** Estilização utilitária e design 100% responsivo (Mobile-First). 
  * **[Vercel](https://vercel.com/):** Plataforma de hospedagem e deployment contínuo (CI/CD).

  ### ✨ Principais Recursos e Boas Práticas 
  * **Componentização Limpa:** Separação das responsabilidades visuais (ex: `ServicoCard`). 
  * **SEO e Open Graph:** Configuração de metadados dinâmicos para pré-visualizações ricas em redes sociais (WhatsApp, LinkedIn, Telegram). 
  * **Otimização de Mídia:** Uso do componente nativo `next/image` para carregamento otimizado de imagens. 
  * **Acessibilidade & Semântica:** Uso apropriado de tags HTML5 (``, ``, ``).

